# Publicação no GitHub

## Nome sugerido do repositório
`MultiChat-for-OBS`

## Descrição sugerida
Unified public live chat dock for OBS Studio — Twitch, YouTube, Kick and TikTok in one place.

## O que publicar
Publique o conteúdo desta pasta, preservando a estrutura. O `.gitignore` foi preparado para não versionar Node.js portátil baixado, `node_modules`, logs ou arquivos `.env`.

## Antes do primeiro push
1. Confira se não existe arquivo `.env` real dentro do projeto.
2. Confira se `runtime/` não contém o Node.js baixado localmente.
3. Confira se `app/node_modules/` não está sendo incluído.
4. Escolha uma licença antes de adicionar um arquivo `LICENSE`. Nenhuma licença foi escolhida automaticamente nesta versão.

## Releases
Para a primeira Release do GitHub, use a tag `v1.0.0` e anexe o ZIP distribuível da versão estável.
