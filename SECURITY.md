# Segurança

O MultiChat for OBS foi projetado para executar localmente e o servidor é vinculado a `127.0.0.1`.

Nunca publique em issues ou commits:
- senhas;
- cookies/sessões;
- tokens OAuth;
- API keys;
- arquivos `.env` reais.

Relatórios de segurança devem evitar exposição pública de credenciais ou dados privados.
